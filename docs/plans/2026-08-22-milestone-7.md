# Milestone 7 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Devices on the same LAN exchange ciphertext over a WebRTC DataChannel. Signalling rides the existing hub WebSocket. Ephemeral items never hit Postgres or R2.

**Architecture:** The Durable Object unicasts `rtc.offer` / `rtc.answer` / `rtc.ice` to the target device. ICE is STUN-only (no TURN). A connection is **Local** when the selected pair uses host candidates. DataChannel payloads are Zod-parsed and still encrypted with VaultKey. Text always persists unless marked ephemeral; ephemeral with no peer fails closed.

**Tech Stack:** `RTCPeerConnection`, Cloudflare STUN, existing HubDO.

**Spec tensions:**

- Spec says P2P images do not need `can_upload`. This milestone ships encrypted text/link over DataChannel. File-over-DC without R2 is the same envelope; the UI sends files on the Local path when the channel is up, otherwise it requires upload access.
- Google/Cloudflare public STUN is free; there is no TURN (locked default).

**Done when:** Signalling is unicast (not broadcast), host candidates classify as Local, ephemeral send does not POST `/api/items`, and an in-process DataChannel path is faster than a delayed server path.

# Milestone 5 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Installable PWA with Serwist, Android Share Target, shortcuts, offline shell, and Web Push that never carries plaintext.

**Architecture:** The service worker intercepts Share Target POSTs, writes plaintext to a local IndexedDB inbox, and redirects home. The signed-in client encrypts and POSTs ciphertext like any other item — the server never sees the share body. Push uses VAPID; payloads are only `New item from {displayName}`.

**Tech Stack:** `@serwist/next`, `serwist`, `web-push`.

**Spec tensions:**

- `VAPID_PRIVATE_KEY` and `VAPID_SUBJECT` are not in the original env list. Public key alone cannot send.
- iOS has no Share Target. Document the Shortcut workaround; do not build it (spec §1.1 / locked default).
- Images in the share sheet wait for Milestone 6 uploads.

**Done when:** A Share Target POST is parsed into local inbox text that the client encrypts, with tests proving the server never receives that plaintext, and unauthenticated push subscribe is denied.

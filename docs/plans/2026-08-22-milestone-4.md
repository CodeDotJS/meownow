# Milestone 4 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Persist encrypted text/link items with a 30-day TTL and fan them out over WebSockets so a second live browser decrypts and can copy without refresh.

**Architecture:** Vercel still owns create/list/delete of ciphertext. After a write it posts an HMAC-ticketed envelope to the Worker, which forwards to the per-user Durable Object. Clients mint a 60s WS ticket and connect to `/ws`. Envelopes carry ciphertext only. P2P DataChannel is Milestone 7.

**Tech Stack:** `@meownow/protocol` envelopes, Cloudflare Durable Object Hibernation API, HMAC tickets (`HUB_SECRET`).

**Spec tensions:**

- Spec §1.7 lists TanStack Query, Zustand, and Dexie. M4 keeps the existing client store; those deps are not required for live fan-out.
- `HUB_SECRET`, `EDGE_URL`, and `NEXT_PUBLIC_EDGE_URL` are not in the original env list. Needed so Vercel can mint tickets and the Worker can verify them. Cookie sessions cannot cross origins.
- Pairing UI still pastes JSON rather than a camera QR (M3 leftover). Not in M4 scope.

**Done when:** Tests show two subscribers receive `item.created` after a persist, and expired/oversize items are denied or omitted.

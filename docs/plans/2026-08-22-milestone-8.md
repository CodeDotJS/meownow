# Milestone 8 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** An admin can list users and devices, revoke a device, remove a member (freeing a seat), read the audit log, and see R2 bytes against the 10 GB free-tier ceiling. Members are denied server-side.

**Architecture:** New `/api/admin/*` routes on `AuthService` / `VaultService`. Usage is summed from `blobs` (committed vs pending). Class A is estimated as `sum(chunk_count)`. Class B is not counted without Worker telemetry.

**Spec tensions:**

- Cloudflare Class A/B ops are not in Postgres. A GraphQL analytics token would be a new paid-adjacent secret. Show an estimate for writes; mark reads uncounted.
- Removing a user deletes Neon rows (cascade) and frees the seat. R2 objects for that user are not deleted here — that is milestone 9 cron.

**Done when:** Admin sees R2 committed bytes vs 10 GiB. A member `GET /api/admin/usage` is `403 forbidden`.

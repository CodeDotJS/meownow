# Milestone 1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship `@meownow/crypto` with every primitive in `docs/SPEC.md` §1.3, including AEAD tamper detection and chunk-truncation detection, before any application route exists.

**Architecture:** Isomorphic WebCrypto plus `hash-wasm` Argon2id. VaultKey is AES-256-GCM, non-extractable after create. AAD binds `item.id || kind || schemaVersion`. Blob chunks use `IV = base_iv (8 bytes) || chunk_index (u32 BE)`. A trailer encrypts `chunk_count` under reserved index `0xffffffff`. Pairing and cross-user send use ECDH P-256 → HKDF-SHA256. BIP39 English wordlist is vendored; no other crypto libraries.

**Tech Stack:** WebCrypto, hash-wasm, Vitest, TypeScript strict.

**Spec tension (do not paper over):** WebCrypto `wrapKey` requires the subject key to be extractable. `createVault()` generates extractable, wraps for recovery, then re-imports non-extractable. Pairing re-wrap uses `rewrapVaultKey` from a wrapped copy, never `exportKey` of the live VaultKey. Document this in `docs/THREAT-MODEL.md`.
